Pasang AIRA di Browser-mu sekarang!

Alat Bantu Verifikasi dan Evaluasi Perizinan Air Tanah untuk evaluator INLINE ESDM. Pasang sekali, selanjutnya diperbarui otomatis.

Langkah pemasangan

  1. 1Pasang Tampermonkey

    Buka Tampermonkey di Chrome Web Store → Tambahkan ke Chrome. Bila diminta, aktifkan Allow User Scripts di detail ekstensi.

  2. 2Pasang lima script

    Klik Pasang pada setiap baris di bawah, lalu pilih Install / Update di halaman Tampermonkey.

  3. 3Isi token

    Refresh INLINE. Di jendela Pengaturan INLINE, isi token pribadi Anda lalu Simpan.

  4. 4Impor data wilayah

    Di panel AIRA, klik Impor Data Wilayah sekali di PC ini.
